# Final Project: Advanced High-Performance Computing

## Abstract
This project synthesizes techniques from previous modules (**01-matrix**, **02-simd**, **03-multicore**, **04-gpu**, **05-mpi**) to implement a comprehensive high-performance computing solution. The goal is to combine SIMD vectorization, multicore parallelism, GPU acceleration, and distributed computing to achieve maximum performance on computationally intensive tasks.

---

## 1. Introduction

- This final project demonstrates the practical application of multiple HPC optimization techniques in a unified implementation.
- I seek to leverage the full spectrum of available computational resources: registers (SIMD), CPU cores (OpenMP), GPU cores (CUDA), and distributed nodes (MPI).
- Objective: To measure the cumulative performance impact of combining these techniques and understand the architectural considerations for hybrid parallel computing.
